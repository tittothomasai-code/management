# DD world view — RBX-2528

Open Operations → DD · World view. The camera moves from Earth to the field and the selected setup wellhead. World, Field and Current well tabs let you move directly. Reduced motion skips the automatic journey. Drag to orbit, pinch or scroll to zoom, and use two fingers or Shift-drag to pan. Surface shows a schematic wellhead marker; Trajectory shows filed plans. Find well opens a historical branch in its own RKB depth frame. Escape returns to Operations without changing the selected source.

Sun & view offers clear daylight preview, sun direction/height and a separate site-sun estimate from location and UTC. Soft directional shadows and a cool fill keep the marker readable. The footer states the lighting mode. Ground, local relief and wellhead symbols are schematic, not surveyed terrain or an as-installed rig. Shadow quality is 1024 on phone and 2048 on desktop. Assets stay local; Natural Earth land is public domain and the existing Three.js library uses MIT.

Private context uses the existing exact-origin Robotyx bridge; no source credentials or session token pass to drilling. Only the registered parent and actual bore may select the linked private master index. Field wellheads use native IDs and projected coordinates, not name joins. The source panel reports catalogue version, missing parts, omitted records and filed plan count. Subsurface geometry is reference-only: actual-bore alignment and historical datum equivalence are not inferred. Projected-to-bit tails stay dashed. This view provides no collision clearance or rig instructions.

Release preserves the published static inventory and existing configuration. It adds the DD directory and lazy launcher, updates the Ops entry, tests the unpublished candidate with synthetic fixtures, verifies payload hashes and promotes only that candidate. Existing Ops, survey, landing, engineering, BHA, reservoir and team checks remain required. Automatic rollback restores the preceding static deploy if publication verification fails. The Robotyx bridge/frontend and well-workspace private reader are companion service changes; they have independent rollback bundles and require no data migration.
